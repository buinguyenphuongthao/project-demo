My recommendation: A-1 or B-1
  • A-1 (Person + Hash): Zero deps, semantically clear — person = account holder name, # = numeric bank code. Most intuitive pairing. Consistent with the rest of the project (all icons are hand-written SVGs).
  • B-1 (Type + Hash): Clean and minimal. The "T" cursor icon is universally understood as text input. Requires npm i lucide-react + tree-shaken import (~10 KB). Worth it if you plan to use icons elsewhere.
  • A-2 Keypad: Clever, but 7 small rectangles become muddy at 16 px on low-DPI screens.
  • B-2 Languages: The globe conveys "language/kana" nicely — slightly more complex path than Type.
  • B-3 / A-3 Search + Calculator: The search icon is redundant (both tabs search), and Calculator is too literal.
